STUDENT DATA PTOCESSOR;
A Python application that processes student grade data from a CSV file and generates performance insights.
FEATURES;
Reads student records from CSV.
Calculates total average.
Computes class average.
Identifies student(s) above average.
Identifies student(s) with the highest & Lowest score.
Performs structured data analysis.
HOW IT WORKS;
The program accepts a CSV file containing student names and scores, processes the data and ouputs calculated results.
BUILT WITH;
Python.
CSV module.
